🕸️ Supernatural - Resumo das Temporadas
Este é um projeto web simples dedicado aos fãs da série Supernatural (Sobrenatural). O site apresenta um resumo detalhado das três primeiras temporadas, destacando os principais acontecimentos da jornada dos irmãos Sam e Dean Winchester, além de um formulário de cadastro para novidades.

🚀 Funcionalidades
Resumo Visual: Galeria com os logotipos icônicos de cada temporada.

Conteúdo Narrativo: Sinopse focada nos arcos principais (Azazel, o pacto de Dean e a abertura do portal do inferno).

Lista de Personagens: Seção dedicada aos protagonistas e vilões (Lilith, Ruby, etc).

Formulário de Inscrição: Área interativa para captura de dados (E-mail, Foto de Perfil e Senha).

🛠️ Tecnologias Utilizadas
HTML5: Para a estruturação do conteúdo e tabelas.

CSS3: Para a estilização, incluindo o fundo temático que remete a um diário ou jornal antigo.

Git & GitHub: Para controle de versão e hospedagem.
