🕸️ Supernatural - Season Summary
This is a simple web project dedicated to fans of the series Supernatural. The website features a detailed summary of the first three seasons, highlighting the key events in Sam and Dean Winchester's journey, along with a newsletter sign-up form.

🚀 Features
Visual Summary: A gallery featuring the iconic logos of each season.

Narrative Content: Synopses focused on the main story arcs (Azazel, Dean’s deal, and the opening of the Devil’s Gate).

Character List: A dedicated section for protagonists and villains (such as Lilith and Ruby).

Sign-up Form: An interactive area for data entry (Email, Profile Picture, and Password).

🛠️ Technologies Used
HTML5: For content structure and layouts using tables.

CSS3: For styling, including a thematic background designed to look like an old diary or newspaper.

Git & GitHub: For version control and hosting.
